# Legacy Draft
## 1. 게임 개요

* **게임명:** Legacy Draft (레거시 드래프트)
* **장르:** 캐주얼 웹 보드게임 / 수집형 카드 게임
* **핵심 목표:** 역대 LoL e스포츠 선수 카드를 뽑아 포지션별(5인)로 배치하고, 제한된 리롤 횟수 내에 최적의 시너지를 맞추어 자신만의 드림팀을 완성하는 것.
* **주요 특징:** '야찌 다이스(Yacht Dice)'의 홀드 & 리롤 시스템을 차용하여 운과 전략적인 선택(시너지 vs 높은 기본 티어)의 재미를 제공.

## 2. 게임 핵심 로직 & 확률 시스템

### 2.1. 드래프트 및 리롤 (야찌 룰)

1. **최초 드래프트:** 게임 시작 시 5개의 포지션에 각각 1장씩 랜덤한 카드가 배치됩니다.
2. **Hold (고정):** 유저는 마음에 드는 카드를 클릭하여 '고정' 상태로 만들 수 있습니다.
3. **Re-roll (다시 뽑기):** 고정되지 않은 나머지 슬롯의 카드를 다시 무작위로 뽑습니다. (최대 3회 제한)

### 2.2. 역방향 가중치 확률 모델

리롤을 할수록 높은 티어의 카드가 나올 확률이 줄어들어, 유저에게 "현재 4성 카드로 시너지를 노릴 것인가, 포기하고 5성을 노릴 것인가"에 대한 심리전과 전략적 고민을 유도합니다.

* **최초 드래프트 확률:** 3성(50%) / 4성(40%) / 5성(10%)
* **리롤(1\~3회차) 확률:** 3성(70%) / 4성(25%) / 5성(5%)

### 3.3. 누적 앵커 보정

같은 팀·시즌 선수는 모두 같은 티어이므로, 위 확률만으로는 팀 시너지를 맞추기가 사실상 불가능합니다. 이를 보완하기 위해 리롤 시 HOLD한 카드 쪽으로 확률을 끌어당깁니다.

* **앵커:** HOLD한 카드 또는 보드에 3명 이상 등장한 팀·시즌 중 가장 많이 모인 팀·시즌 (동률이면 높은 티어 우선).
* **보정 확률:** 리롤되는 각 슬롯이 앵커 팀·시즌의 해당 포지션 선수로 나올 확률이 리롤 회차마다 **10% → 20% → 30%**로 증가하며, **같은 시즌+팀 선수가 3명 이상 등장한 상태라면 +15%p 추가 상승(25% → 35% → 45%)**합니다. 실패 시 4.2의 리롤 확률표로 드로우.
* 리롤할수록 고티어 확률은 낮아지고 시너지 확률은 높아지므로 "고티어 vs 시너지" 선택이 더 선명해집니다.

## 3. 시너지 시스템

5개의 슬롯이 모두 채워졌을 때, 배열을 순회하며 일치하는 속성에 따라 최종 티어와 시각적 이펙트가 부여됩니다. 카드별로 적용 가능한 보너스 중 가장 큰 것 하나만 적용됩니다 (중첩 없음). 최대 티어는 5성이며, 레전더리만 6성까지 도달할 수 있습니다.

* **동일 팀 시너지 그룹 (프랜차이즈 계보):**
  다음 팀들은 팀명이 변경되었거나 형제팀 관계이므로 팀 시너지(프레스티지, 부분 시너지) 판정 시 동일한 팀으로 취급합니다. 단, **레전더리**는 정확히 같은 단일 팀과 같은 시즌 5장일 때만 발동합니다.
  `SKT-T1`, `NBS-NWS`, `SSW-SSB-SSG-GEN`, `DWG-DK`, `LZ-KZ-DRX`, `KOO-ROX-HLE`, `SPY-MAD`, `SN-WBG`, `SHR-RYL-RNG`, `CLG-NRG`
* **부분 시너지 (Team 3/5, 4/5):**
  * **조건:** 5장 중 3~4장이 '같은 팀'일 경우
  * **보상:** 해당 카드만 티어 +1, 초록색 프레임 (4장일 때는 맥동하는 빛 효과 추가)
* **기본 보상 (같은 리그 또는 같은 시즌):** 기본 티어 +1 상승, 프레임 색상 변경
* **프레스티지 (Prestige):**
  * **조건:** 5장의 카드가 모두 '같은 팀'일 경우
  * **보상:** 카드 최종 티어 +1 상승, 은은하게 흐르는 금빛 테두리 및 홀로그램 오버레이 효과
* **레전더리 (Legendary):**
  * **조건:** 5장의 카드가 모두 '같은 팀'이면서 '같은 시즌'일 경우
  * **보상:** 카드 최종 티어 +2 상승 (6성 한계 돌파), 마우스 호버 시 빛반사 각도가 변하거나 입자가 흩날리는 동적 홀로그램 이펙트 부여

## 4. 부가 시스템

* **도감 시스템:** 게임 중 한 번이라도 뽑은 카드는 Local Storage에 `id` 값으로 기록되어, 메인 화면의 '도감' 메뉴에서 활성화된 상태로 열람할 수 있습니다.
* **공유 시스템:** 3회의 리롤이 끝나고 팀이 최종 완성되었을 때, 해당 화면을 하나의 이미지로 병합하여 기기에 저장하거나 SNS에 공유할 수 있는 버튼을 제공합니다.
